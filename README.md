# Steam Backlog Clear Manager 사용 가이드

Steam 라이브러리 HTML 원본 데이터를 분석하여 미클리어 게임을 도출하고, 개인 맞춤형 우선순위와 진행 상황 추적용 단일 HTML 체크리스트 웹앱을 생성 및 활용하는 전체 가이드입니다.

---

## 1. 개요

Steam 라이브러리에 게임이 쌓여갈수록 무엇부터 끝내야 할지 결정하기 어려워집니다.
이 도구와 분석 워크플로우는 사용자의 Steam 프로필 게임 페이지 HTML 원본을 파싱하여 다음 작업을 수행합니다.

- 멀티플레이/샌드박스/유틸리티 자동 제외
- 플레이 타임 및 도전 과제(Achievement) 달성률 기반 미클리어 게임 선별
- HowLongToBeat 및 공략 데이터 기준 잔여 시간 산출
- 백로그 제거 효율 중심의 우선순위(1~100점) 평가
- 브라우저 로컬 저장소(LocalStorage)와 연동되는 단일 파일 웹 체크리스트 생성

---

## 2. 사전 준비: Steam 라이브러리 HTML 추출

Steam 웹사이트에서 자신의 라이브러리 페이지 원본을 HTML 파일로 저장해야 합니다.

1. 웹 브라우저(Chrome, Edge, Firefox 등)를 엽니다.
2. Steam 커뮤니티에 로그인한 뒤 자신의 게임 목록 페이지로 이동합니다.
   - 주소 형식: `https://steamcommunity.com/id/[본인ID]/games/?tab=all`
   - 또는 `https://steamcommunity.com/profiles/[본인SteamID64]/games/?tab=all`
3. 페이지의 모든 게임 목록이 브라우저 화면에 정상적으로 렌더링되도록 확인합니다.
4. 키보드 단축키 `Ctrl + S` (macOS는 `Cmd + S`)를 누릅니다.
5. 저장 형식을 반드시 **웹페이지, 단일 파일** 또는 **웹페이지, 완료(HTML)** 로 선택하여 `.html` 파일로 저장합니다.
6. 이 페이지 하단에 있는 초기 프롬프트 내용을 복사해서 html 파일 업로드와 함께 GPT나 제미나이에서 같이 사용하면 됩니다.

## 3. 분석 프로세스 및 평가 기준

### 3.1 분석 제외 대상
다음 게임은 캠페인 백로그 제거 목적에 맞지 않으므로 자동으로 제외됩니다.
- 멀티플레이 전용 또는 서비스형 온라인 게임 (예: Warframe, Albion Online 등)
- 명확한 엔딩이 없는 샌드박스/시뮬레이션 (예: Cities: Skylines, Euro Truck Simulator 2 등)
- 게임 실행 및 보조 유틸리티 (예: Lossless Scaling)
- 본편 엔딩 관련 핵심 도전 과제를 이미 달성한 완료 게임

### 3.2 평가 기준 (100점 만점)
단순히 메타크리틱 점수가 높은 대작보다, 실제로 시작해서 끝낼 수 있는 게임에 높은 가중치를 부여합니다.

- 클리어 용이성 (25점): 조작 난이도, 시스템 복잡도, 공략 의존도
- 예상 잔여 플레이 시간 (20점): 엔딩까지 남은 순수 플레이 시간
- 게임 완성도 및 평가 (20점): 스토리 흡입력 및 플레이 만족도
- 현재 진행도 (15점): 이미 진행해 둔 세이브/도전과제 분량
- 개인 취향 적합성 (10점): 선호 장르 및 플레이 패턴
- 최근 관심 가능성 (5점): 최근 실행 여부 및 접근성
- 방치 보너스 (5점): 오래 묵혀둔 게임 청산 보너스

### 3.3 카테고리 구분
- 🔥 지금 바로 클리어 추천: 잔여 시간 5시간 미만, 즉시 1개 청산 가능한 타이틀
- ⭐ 다음 차례 추천: 10시간 안팎의 군더더기 없는 명작
- 🎮 장기 프로젝트: 30~50시간 이상의 대형 RPG 및 전략 시뮬레이션
- 💤 나중에: 피로도가 높거나 특정 상황에 어울리는 서브 타이틀
- ❓ 상태 확인 필요: 세이브 파일이나 DLC 상태 점검이 필요한 타이틀

## 4. 체크리스트 웹앱 (HTML) 활용법

분석 결과로 생성된 단일 `.html` 파일은 별도 웹서버나 의존성 설치 없이 즉시 실행됩니다.

### 4.1 실행 방법
- 다운로드한 HTML 파일을 Chrome, Edge, Safari 등 브라우저로 더블 클릭하여 실행합니다.

### 4.2 주요 기능
1. 자동 진행률 표시
   - 상단 헤더에 `전체 N개 중 M개 클리어 (X.X%)` 형태의 카운터와 게이지 바가 실시간 갱신됩니다.
2. 상태 영구 저장 (LocalStorage)
   - 체크박스를 클릭하여 클리어 처리하면 브라우저 내부 LocalStorage에 즉시 보관됩니다.
   - 브라우저를 닫거나 새로고침해도 진행 상태가 유지됩니다.
3. 실시간 필터링 및 검색
   - 검색창: 게임 제목 일부 입력 시 실시간 필터링
   - 카테고리 드롭다운: 지금 바로 추천 / 다음 차례 / 장기 프로젝트 등 분류별 보기
   - 완료된 게임 숨기기: 클리어한 타이틀을 가려 남은 백로그에만 집중 가능

## 1. Steam 라이브러리 HTML 데이터 분석

사용자가 업로드한 **Steam 프로필 게임 페이지의 HTML 파일**을 Steam 라이브러리의 원본 데이터로 사용한다.

사용자는 Steam 웹사이트에서 자신의 게임 목록 페이지를 브라우저로 열고, 해당 페이지를 HTML 파일로 저장하여 업로드한다.

### 데이터 처리 원칙

- HTML 파일 자체를 직접 분석한다.
- CSV, JSON 등의 별도 변환 파일을 요구하지 않는다.
- HTML의 DOM 구조, HTML 속성, 링크, JavaScript 데이터, JSON 형태로 삽입된 데이터 등에서 게임 정보를 추출한다.
- 동일한 게임이 HTML 내부에 여러 번 나타나는 경우 중복 제거한다.
- HTML에 실제로 존재하지 않는 정보를 추측하여 생성하지 않는다.
- HTML에 포함된 정보와 외부에서 조사한 정보를 명확하게 구분한다.

가능한 경우 HTML에서 다음 데이터를 추출한다.

- AppID
- 게임명
- 플레이 시간
- 최근 플레이 날짜
- Steam Achievement 진행도
- Achievement 달성 정보
- 게임 링크
- 기타 게임 진행 상태를 판단하는 데 유용한 Steam 데이터

HTML에서 추출할 수 없는 정보는 외부 자료를 조사하여 보완할 수 있다.

단, 외부 자료를 통해 보완한 정보는 **HTML에서 직접 확인한 정보가 아님을 구분하여 표시한다.**

### HTML 데이터가 불완전한 경우

HTML에 필요한 데이터가 없거나 일부 게임 정보만 포함되어 있는 경우 다음 원칙을 따른다.

1. HTML에 존재하는 정보부터 최대한 활용한다.
2. 부족한 정보는 Steam 및 신뢰할 수 있는 외부 자료를 조사하여 보완한다.
3. 외부 조사로도 확인할 수 없는 정보는 추측하지 않는다.
4. 데이터가 부족하여 클리어 여부를 판단할 수 없는 게임은 `클리어 여부 불명`으로 분류한다.

---

### 엔딩 및 클리어 여부 판단

Steam에서 직접 "엔딩을 보았는지"를 확인할 수 없는 경우 이를 임의로 단정하지 않는다.

다음 자료를 조합하여 클리어 여부를 판단한다.

1. HTML에서 확인되는 엔딩 관련 Steam Achievement
2. 주요 스토리/보스/최종 챕터 관련 Achievement
3. Achievement 달성 여부
4. 플레이 시간
5. 게임의 일반적인 메인 스토리 클리어 시간
6. 기타 신뢰할 수 있는 게임 진행 정보

판정은 다음 세 단계로 구분한다.

- **확실히 미클리어**
- **미클리어 가능성이 높음**
- **클리어 여부 불명**

`클리어 여부 불명`인 게임은 근거 없이 미클리어 목록에 넣지 않는다.

Achievement가 존재하지 않거나 Achievement만으로 엔딩 여부를 판단하기 어려운 게임 역시 무리하게 판정하지 않는다.

## 2. 분석 대상

다음 게임은 우선순위 분석 대상에서 제외한다.

- 본편 엔딩을 이미 확인한 게임
- 엔딩 Achievement를 달성한 게임
- 명확하게 클리어한 것으로 판단되는 게임
- Endless / Sandbox / Multiplayer 중심 게임 중 명확한 엔딩 목표가 없는 게임

단, 게임 자체의 구조상 엔딩 이후에도 계속 플레이하는 게임은 **본편 엔딩 달성 여부**를 기준으로 판단한다.

---

## 3. 게임별 외부 정보 조사

각 미클리어 게임에 대해 가능한 경우 다음 정보를 조사한다.

- 장르
- 메인 스토리 예상 플레이 시간
- 메인 + 추가 콘텐츠 플레이 시간
- 난이도
- 게임의 전반적인 평가
- 스토리 중심인지 게임플레이 중심인지
- 반복 플레이가 필요한지
- 엔딩까지의 난이도
- 놓치기 쉬운 요소
- DLC가 본편 클리어에 영향을 주는지
- 현재 플레이 상태를 판단할 수 있는 정보

가능하면 신뢰도 높은 자료를 우선 사용한다.

게임 공략이나 진행 관련 정보는 일본어 자료가 존재한다면 일본 자료도 적극적으로 참고한다.

## 4. 우선순위 평가

각 게임을 100점 만점으로 평가한다.

### 평가 기준

- 클리어 용이성: 25점
- 예상 잔여 플레이 시간: 20점
- 게임 완성도/평가: 20점
- 현재 진행도: 15점
- 개인 취향 적합성: 10점
- 최근 관심을 가질 가능성: 5점
- 오래 방치된 게임에 대한 보너스: 5점

목적은 단순히 "가장 좋은 게임"을 찾는 것이 아니다.

목적은 **"내가 실제로 시작해서 엔딩까지 볼 가능성이 높은 게임"​**을 찾아내는 것이다.

따라서 높은 평가를 받은 장시간 게임보다, 이미 상당 부분 진행했고 남은 플레이 시간이 짧은 게임이 더 높은 순위를 받을 수 있다.

---

## 5. Backlog 제거 효율

각 게임에 다음 정보를 별도로 계산한다.

- 예상 총 클리어 시간
- 현재까지 플레이 시간
- 예상 잔여 시간
- 백로그 제거 효율

"백로그 제거 효율"은 짧은 시간 안에 게임 하나를 완결할 수 있는 정도를 의미한다.

예:

- 이미 70% 진행 + 잔여 5시간 → 매우 높음
- 처음부터 시작 + 10시간 게임 → 높음
- 처음부터 시작 + 100시간 RPG → 낮음

단순히 플레이 시간이 짧다는 이유만으로 높은 점수를 주지 말고 현재 진행도와 함께 평가한다.

## 6. 결과 표

최종 결과를 다음 열을 가진 표로 출력한다.

| 순위 | 게임 | 클리어 상태 | 현재 진행 추정 | 예상 잔여시간 | 난이도 | 클리어 부담 | Backlog 효율 | 추천점수 |
|---:|---|---|---:|---:|---|---|---|---:|

게임마다 다음 내용을 간단히 설명한다.

### 추천 이유

왜 이 게임을 이 순위에 배치했는지 2~4문장으로 설명한다.

특히 다음을 중요하게 설명한다.

- 지금 시작하기 좋은 이유
- 예상되는 클리어 부담
- 이미 진행한 정도
- 다른 게임보다 우선할 가치
- 주의해야 할 요소

## 7. 카테고리 분류

전체 게임을 다음과 같이 추가 분류한다.

### 🔥 지금 바로 클리어 추천

짧은 시간과 낮은 부담으로 엔딩을 볼 가능성이 높은 게임.

### ⭐ 다음 차례 추천

지금 시작해도 좋은 게임.

### 🎮 장기 프로젝트

플레이 시간이 길거나 난이도가 높지만 클리어 가치가 높은 게임.

### 💤 나중에

현재 시점에서 우선순위가 낮은 게임.

### ❓ 상태 확인 필요

클리어 여부 또는 진행 상태를 확실히 판단할 수 없는 게임.

## 9. 체크리스트 웹페이지 생성

분석이 끝나면 결과를 기반으로 하나의 독립적인 HTML 파일을 생성한다.

외부 라이브러리나 서버에 의존하지 않는 단일 HTML 파일이어야 한다.

다음 기능을 구현한다.

- 게임별 체크박스
- 완료 게임 취소선 표시
- 완료 게임 숨기기
- 전체 게임 수 표시
- 완료 게임 수 표시
- 전체 완료율 표시
- 우선순위 순 정렬
- 예상 플레이 시간 표시
- 난이도 표시
- 추천점수 표시
- 카테고리 표시
- 게임 검색
- 카테고리 필터
- 완료 상태 필터
- 브라우저 LocalStorage를 이용한 체크 상태 저장

페이지를 다시 열어도 체크 상태가 유지되어야 한다.

게임을 완료하면 해당 게임의 체크박스를 체크하고 완료된 게임은 시각적으로 구분한다.

상단에는 다음과 같은 진행 상황을 표시한다.

> "Steam Backlog: 47개 중 12개 클리어 — 25.5%"

게임 수와 완료율은 실제 분석 결과에 따라 자동으로 계산한다.

---

## 10. 중요한 분석 원칙

- 근거 없는 클리어 여부 추정을 하지 않는다.
- 정보가 불확실하면 불확실하다고 명시한다.
- 게임 평점만으로 순위를 결정하지 않는다.
- 장시간 게임이라고 무조건 낮은 순위를 주지 않는다.
- 현재 진행도가 높은 게임은 적극적으로 우선순위를 높인다.
- 엔딩까지의 실제 부담을 고려한다.
- DLC는 본편과 별도로 판단한다.
- 온라인 서비스 종료 여부나 서버 상태가 클리어 가능성에 영향을 주면 표시한다.
- 게임이 지나치게 오래되었거나 현대 시스템에서 플레이하기 어려운 경우 별도로 표시한다.
- 동일 게임의 리메이크/리마스터/원작이 라이브러리에 함께 있으면 구분한다.
- **HTML에서 확인한 사실과 외부 자료에서 확인한 사실을 혼동하지 않는다.**
- **HTML에 존재하지 않는 플레이 기록이나 Achievement 정보를 임의로 만들어내지 않는다.**
- **HTML 파일의 게임 목록이 불완전하다고 판단되면 전체 라이브러리를 분석한 것처럼 표현하지 않는다.**
- **Steam HTML의 데이터 구조가 변경되었더라도 가능한 범위에서 의미 있는 데이터를 추출하되, 추출에 실패한 정보는 명시한다.**

## 11. 결과 형식

최종 결과는 다음 순서로 출력한다.

1. 분석 방법 및 데이터 신뢰도
2. HTML에서 추출한 Steam 라이브러리 데이터 요약
3. 미클리어 게임 전체 목록
4. 추천 우선순위 TOP 20
5. 카테고리별 분류
6. 게임별 추천 이유
7. 장기 프로젝트 추천
8. 클리어 여부 확인이 필요한 게임
9. 최종 플레이 큐
10. 체크리스트용 독립 HTML 파일

가능한 경우 각 게임의 정보 출처도 함께 표시한다.

---

## 12. 입력 데이터에 대한 추가 원칙

사용자가 업로드하는 HTML은 **Steam 프로필의 게임 목록 페이지를 브라우저에서 직접 저장한 원본 HTML**이다.

따라서 HTML 자체를 우선적인 사용자 데이터 소스로 취급한다.

별도의 CSV 또는 JSON 파일을 요구하지 않는다.

사용자가 여러 개의 HTML 파일을 업로드한 경우 각각의 데이터를 통합하여 하나의 Steam 라이브러리로 분석한다.
